# Tuition Management System

## Overview

A tuition and school registration management system designed to simplify student enrollment and record management.

This project was built to reduce manual paperwork in educational institutions.

---

## Problem

Many tuition centers still use paper registers for:

- Student registration
- Contact details
- Fee records
- Batch management

This creates inefficiency and increases the chance of data loss.

---

## Solution

A centralized digital system for managing tuition center operations.

---

## Features

- Student Registration
- Batch Management
- Student Records
- Fee Information
- Search Students
- Data Management
